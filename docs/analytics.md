# 블로그 분석 이벤트

GTM 웹 컨테이너는 `GTM-T7H7JNZ5`를 사용한다. GA4 측정 ID는 `G-SW73FSL7LQ`를 유지한다. GTM 웹 컨테이너의 Google 태그가 초기 페이지 조회와 SPA History 변화를 측정한다. 앱은 `page_view`를 직접 발행하지 않는다.

GTM 맞춤 이벤트 트리거는 아래 이벤트 이름에 정확히 일치시킨다. 전체 이벤트 정규식이나 History Change 트리거를 이 이벤트 태그에 연결하지 않는다.

| 이벤트 | 발생 시점 | 데이터 영역의 매개변수 |
|---|---|---|
| `view_post` | 게시글 화면 진입 | `post_title`, `post_slug` |
| `search` | 검색 창에서 검색 결과 선택 | `search_term`, `result_count` |

앱이 두 이벤트와 함께 `page_location`·`page_title`을 데이터 영역에 전달하고, GA4 이벤트 태그에서 이 값을 연결해 SPA 이동 전 주소에 이벤트가 연결되지 않도록 한다. 페이지뷰용 GA4 이벤트 태그를 추가하지 않는다.

게시 후 첫 접속, 게시글 이동, 검색 결과 이동, 뒤로 가기에서 `page_view`가 화면당 한 번 전송되는지 확인한다. `view_post`에는 글 제목·slug, `search`에는 검색어·결과 수가 전달되는지도 실제 수집 요청으로 확인한다. 전송 요청과 GA4 표준 보고서 반영은 별도로 확인한다.
